* Darts Strategy
I frequently play a solitary darts game called 50 which I made up, and in this project I will be deriving the optimal strategy. The rules are the game are as follows:
1) Given three darts, score exactly 50 points
2) Bullseye can count for any value between 1 and 50

The question I will answer is, given an accuracy distribution, where is the optimal aiming point for every possible situation in the game?
